# Equilíbrio

Projeto privado de finanças pessoais e organização da Casa para Windows.

A aplicação e as instruções de desenvolvimento encontram-se em `equilibrio/`. SQLite mantém os dados no perfil do utilizador, fora da instalação. As atualizações continuam a utilizar `.fpupdate`.

O repositório contém código e recursos do programa. Não contém dados pessoais, perfis, cópias de segurança nem chaves privadas.
