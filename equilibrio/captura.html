    Transfere o ficheiro JSON para o computador e abre Dados → Capturas → Importar capturas. Exportar mantém a cópia neste dispositivo; repetir a importação não duplica capturas.

    Esta página funciona sem cloud. As capturas ficam neste navegador, sem envio automático. Podes copiar o ficheiro captura.html para o telemóvel e abri-lo no navegador. Limpar os dados do navegador pode remover capturas ainda não exportadas.
